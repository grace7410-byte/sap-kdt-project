# 러닝허브 연습문제 PDF 모으기 + Claude 학습 튜터 세팅

## 목적 / 상황
서티 준비를 위해 SAP 러닝허브의 Hands-on Practice 시스템에서 제공하는 연습문제/솔루션 PDF를 최대한 많이 확보하고, 이를 Claude 프로젝트에 업로드해서 전담 학습 튜터로 활용하는 방법. (참고: 이 절차 자체를 꼭 거칠 필요는 없고, 각 모듈 실습 가이드 문서를 보고 바로 실습을 진행해도 무방함.)

## 절차

### 1) PDF 모으기 (연습문제/솔루션 획득)
1. **Get certified** 메뉴에서 시험 볼 서티에 접속한다.
2. **Prepare** 버튼 클릭 → 스크롤하며 해당 모듈/시험을 준비하기 위한 과정이 어떻게 구성되어 있는지 확인한다.
3. 새 창을 열고 **Browse → By learning type → Hands-on practice**에 접속한다.
4. 앞선 Prepare 화면에서 확인한 과정 코드(예: `S4500`)를 핸즈온 검색창에 그대로 검색해 Practice System에 접속한다.
5. **Enroll** 클릭 → being prepared 상태로 대기.
6. **Access** 버튼이 뜨면 클릭 → EN 또는 KO 버전 가이드를 다운로드한다.
7. **Close** → **Remove** 클릭으로 프랙티스 시스템을 바로 반납한다.
   - Practice System은 한 번에 2개까지만 사용 가능하기 때문에, 가이드 PDF만 받고 바로 반납한 뒤 다음 과정으로 넘어가는 게 핵심이다.
8. 이 과정을 반복하면서 모듈별(MM, FI 등) 연습문제 PDF를 모은다.

### 2) Claude 프로젝트로 AI 학습 튜터 만들기
1. Claude에서 새 프로젝트를 생성한다. (무료 플랜 기준 프로젝트는 5개까지 생성 가능)
2. 프로젝트명 예시: `SAP [시험명] Certification 취득 & AI 학습 도우미`
3. 프로젝트 설명(목표) 예시:

   > **프로젝트 목표**: SAP `[시험명]` 자격증의 효율적인 문제 풀이 및 단기 취득을 위해 Claude를 전담 학습 튜터로 활용합니다.
   >
   > **주요 작업 내용**
   > - 연습 교재 학습: SAP 연습 문제 PDF(Practice PDF)를 클로드에 업로드하여 관련 이론 및 솔루션 데이터베이스 구축
   > - 맞춤형 필기노트 생성: Task를 수행할 때마다 해결 과정과 핵심 요약을 바탕으로 상세 필기노트 작성 요청
   > - 문제 풀이 솔루션 검색: 막히거나 에러가 발생하는 문제 입력 시, 업로드된 PDF 자료에서 유사 유형을 탐색하여 Step-by-Step 해결법 가이드 제공
   > - 시험 가이드 구축: 필기노트 및 문제 풀이 데이터를 바탕으로 모의 실기 테스트 수행 및 오답 문제 복습

4. 프로젝트 지침(Instructions)에 아래 템플릿을 시험명·파일명에 맞게 고쳐서 넣는다. (예시는 FI · MM)

**FI (C_TS4FI) 지침 예시**
```
# SAP 자격증 학습 튜터 지침 (Instruction)

## 역할 및 목표
너는 SAP FI 자격증(C_TS4FI) 취득을 돕는 전문 AI 튜터이다.
컨텍스트에 업로드된 PDF 파일들을 바탕으로 질문에 답하고, 문제 및 오류 해결을 돕는다.

## 컨텍스트 문서 데이터베이스 (참고 파일 역할)
1. `C_TS4FI_EN_2601_Task_Instructions.pdf`
   - **실제 시험 문제 / 실기 Task 지침서**
   - 사용자가 풀어야 하는 실제 시험 문제 및 Task 지침이 담긴 핵심 문서.
2. `SAP_LA_S4F12_EN_26_EX.pdf`, `SAP_LA_S4F15_EN_26_EX.pdf`, `SAP_LA_S4F17_EN_26_EX.pdf`, `SAP_LA_F16A1_EN_26_EX.pdf`
   - **공식 연습 문제 및 솔루션 교재 (Practice PDF)**
   - 각 모듈/단원별 실습 예제와 단계별 정답/해설(Solution)이 담긴 문서.

## 문제 해결 알고리즘 (작업 절차)
1. 사용자가 특정 Task, 문제 번호, 또는 에러 메시지를 입력하면, 먼저 `C_TS4FI_EN_2601_Task_Instructions`에서 해당 시험 문제를 확인한다.
2. 해당 시험 문제와 관련된 개념 및 풀이법을 4개의 **연습 문제 교재 PDF**에서 검색하여 유사 예제와 공식 솔루션을 찾아낸다.
3. 문제의 원인과 Step-by-step 해결 방법(Fiori App 이름, T-Code, 메뉴 경로, 주요 입력값 등)을 명확히 안내한다.

## 주의 사항
- 단순 답만 제시하지 말고, 왜 해당 메뉴/Fiori App으로 가야 하는지 논리적 이유를 함께 설명할 것.
- 연습 문제 교재 PDF에 명시된 공식 솔루션 절차를 최우선으로 참고할 것.
- 사용자가 별도로 "필기노트 정리해줘" 또는 "요약해줘"라고 명시적으로 요청할 때에만 핵심 요약본을 작성할 것. (평소 답변에서는 자동 요약 금지)
```
