# FI (2026-08-10)

**러닝허브 서버**: S4F12

## 실습 절차

### `BP` Business Partner 관리
- 본인 코드(##) 포함된 BP 더블클릭 → 수정 모드에서 원하는 Role 선택 가능
- 상단 Company Code 진입 → 조정계정(Reconciliation Account) 관리
- 예: FLVN00(FI 벤더) → 21100000 계정 사용. Role마다 맞는 Recon 계정 확인 가능

### `FS00` G/L계정 조회
- `BP`에서 확인한 Vendor 회사코드 1710의 Reconciliation Account(21100000) 재확인
- 계정 21100000 / 회사코드 1710 조회 → Control 탭에서 Recon. Account for Acct Type = `K`(Vendors)
- 즉 이 계정은 회사코드 1710의 Vendor 보조원장 Reconciliation Account이며, Vendor 거래 발생 시 이 G/L 계정에도 자동 반영됨

### `SE11` DB Table `SKB1` 조회
- MITKZ = `K` 조건으로 조회 → FS00에서 확인한 21100000 계정이 목록에 포함됨을 재확인
- 회사코드 1710에서 Vendor 관련 Reconciliation Account로 사용 가능하도록 설정된 G/L 계정임을 확인

### `OBA7` 전표유형 세팅
- 경로: `SPRO` → Financial Accounting → Accounts Receivable and Accounts Payable → Business Transactions → Postings with Alternative Reconciliation Account → Other Special G/L Transactions → Make and Check Document Settings → Define Document Types
- 또는 T-Code `OBA7` 직접 접근, 하단 토글에서 Document Types의 Transaction 확인 가능
- WL/WE/WA 등 전표유형 리스트 확인

**cf. WA vs WL 차이 (SD 8/7 실습 중 생긴 질문)**
- 생산출고, 재고실사 출고 → `WA`
- 고객 판매 출고 처리(PGI) → `WL`
- 모든 계정 유형에 전표를 전기할 수 있는 건 아니고, OBA7의 Account types allowed 옵션에 따라 허용 계정 유형(Assets, Material, G/L Account 등)이 결정됨

### `FB01` 전기키를 이용한 수동 전표 생성
- 문서일 + 전표유형(`SA`) 입력 후 엔터
- 전기키 `40`: G/L 계정 차변 → 계정 `10010000`(Petty Cash, 소액현금), Amount 3000
- Next Line item → 전기키 `50`: G/L 계정 대변 → 계정 `15200000`(가지급금/급여 선급금)
- 회계적 의미: 직원이 미리 받아간 급여 선급금 3,000을 회사 소액 현금으로 반납받은 거래
  - 차변: Petty Cash / 대변: Salary and Wages Advances
- 저장 시 바로 문서 생성 (또는 엔터로 대변 아이템 세부내역 이동, Next line item으로 행 추가 가능)

### `FB03` 전표 조회
- 생성한 문서번호로 조회 → 입력한 금액, 차/대 아이템, 전표 헤더 정보 확인 가능

### `OB13` Chart of Account 리스트
- 경로: `SPRO` → Financial Accounting → General Ledger Accounting → Master Data → G/L Accounts → Preparations → Edit Chart of Accounts List
- 또는 T-Code `OB13`
- **Chart of Accts: YCOA** — 회사코드에 YCOA를 할당하면 그 회사는 YCOA에 정의된 8자리 G/L 계정(10010000, 15200000 등)으로 회계 전표 작성 가능
- **Group Chart of Accts: CONS** — 연결 재무제표 작성을 위해 YCOA 하위 개별 G/L 계정이 그룹 계정과목표 CONS와 매핑됨
