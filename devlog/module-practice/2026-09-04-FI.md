# FI (2026-09-04)

## cf. 개념 정리
- FI 서티(C_TS4FI) 실습 Task 3: 청구 데이터 자동 업로드를 위한 전용 Document Type 생성 + 채번 규칙 정의 + 벤더(BP) 등록
- Document Splitting 분류에서 신규 Document Type도 기존 KR(Vendor Invoice)과 동일한 Transaction/Variant 값을 넣어줘야 하는 것 확인
- Business Partner는 Roles 탭에 FI Vendor(FLVN00) role이 있어야 Company Codes 탭이 노출됨
