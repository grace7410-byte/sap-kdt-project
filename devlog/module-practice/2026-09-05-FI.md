# FI (2026-09-05)

## cf. 개념 정리
- FI 서티(C_TS4FI) 실습 Task 4: 연체채권 정률법 개별 가치조정(flat-rate individual value adjustment) 설정 + Valuation Run
- Value Adjustment Area는 Define Valuation Areas 화면만으로는 Ledger 매핑이 안 보여서, Assign Valuation Areas and Accounting Principles → Check Assignment of Accounting Principle to Ledger Group 순으로 역추적해야 확인 가능
- BP(고객) 마스터에 Value Adjustment Key를 미리 세팅해두지 않으면 Valuation Run에서 조정액이 0으로 나오는 것을 뒤늦게 발견 → Run 재실행 필요했음

## 실습 절차
- Task 4 (Value Adjustment Key 생성 → Customer BP 생성 → 청구서 2건 전기 → Valuation Run 실행/검증) 진행
- 상세 절차·에러 대응은 [`서티 - FI 실습 가이드 - Task 4`](../guides/certification/fi-cert-practice-guide.md#task-4) 참고
