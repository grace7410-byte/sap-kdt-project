### Behavior Definition 착수 (Root/Projection + LOCAL 클래스)
- `ZR_B07_MARA`, `ZC_B07_MARA` BDEF 2개 생성, Interface 쪽에 LOCAL 클래스 생성
- 아직 전체 필드 제어/Validation은 안 붙은 골격 단계 (Draft, Etag, Mapping, 일부 Field 제어만 진행)

cf. Draft 처리
- Interface에 `with draft;`, Projection에 `use draft` 추가
- Root: `association _MaraText { create; with draft; }` 추가
- Child: `association _Mara { with draft; }` 추가
- Draft 테이블: Root `draft table ztb07mara_d`, Child `draft table ztb07mara_td` 생성
- Root에 Draft Action 5개 정의
```
draft action Edit;
draft action Activate;
draft action Resume;
draft action Discard;
draft determine action Prepare;
```
- Projection에 `use action Edit/Activate/Resume/Discard/Prepare;` + `with draft;` 각각 추가

cf. Field 제어 (1차)
- Root: `field ( numbering : managed, readonly ) MatUuid;`
- Child: `field ( readonly ) MatUuid;`, 언어 키(Spras)는 업데이트 때만 수정 불가하도록 `field ( readonly : update ) Spras;`

cf. Etag / Mapping
- Root Etag:
```
total etag ChangedAt
authorization master ( instance )
etag master LocChangedAt
```
- Root Mapping: `ztb07mara` corresponding, 대부분 자동 매핑되는 필드는 주석 처리하고 changed_at/by, created_by, creation_at, loc_changed_at, mat_uuid만 명시
- Child Mapping: `ztb07mara_t` corresponding, mat_uuid만 명시

> BDEF는 아직 fragment 단계라 별도 코드 파일로는 안 올렸어요. 전체 필드 제어(mandatory/readonly)와 Validation이 붙어서 완성된 형태가 나오면 그때 `src/01_material-mgmt/bdef/`에 정식으로 추가할게요.
