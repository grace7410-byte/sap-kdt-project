#### 언어 ([`ZI_B07_SPRAS_F4`](../../reference/00_common-searchhelp.md) · [코드 보기](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/00_common-searchhelp/cds/ZI_B07_SPRAS_F4.ddls.asddls))
마찬가지로 원본 테이블 `T002T` 사용 예정이었는데, 이번엔 하드코딩이 아니라 `ztb07mara_t`를 베이스로 가져오는 방식이라 여러 번 잘못 짚었다.

🐛 문제 — 잘못된 시도들
1. `ztb07mara_t`와 `t002t`를 `spras = spras and sprsl = 세션언어`로 조인 → 결과에 "3(태국어 코드) 자리에 영어"가 나오는 이상한 현상 발견
2. 조인 조건을 `b.spras = b.sprsl`로 바꿔봄 → 더 이상해짐
3. `sprsl` 조건을 주석 처리해보니 "3 안에 여러 언어, E 안에 여러 언어"가 한꺼번에 나옴
   → **`ztb07mara_t`의 `spras`와 `t002t`의 `spras`/`sprsl`을 같은 의미로 취급하면 안 된다**는 걸 확인

✅ 해결
- 원인: 원본 테이블을 텍스트 테이블(`t002t`)로만 쓰려고 해서 발생. 언어 텍스트 테이블이 아니라 **언어 테이블(`T002`) 자체**를 조인해야 함
- 1차 수정(3, E에 대해 KO, EN까지만 끌어오기): `ztb07mara_t` + `t002` 조인
- 최종(텍스트까지 제대로 가져오기): **JOIN을 두 번** 해야 했음 — `t002`로 언어코드(KO/EN) 매핑 후, `t002t`로 언어명 텍스트까지 매핑

```
@AbapCatalog.viewEnhancementCategory: [#NONE]
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '언어 F4 Help'
@Metadata.ignorePropagatedAnnotations: true
@ObjectModel.resultSet.sizeCategory: #XS
@Search.searchable: true

define view entity zi_b07_spras_f4
  as select distinct from ztb07mara_t as a
    inner join            t002        as b on a.spras = b.spras
    left outer join       t002t       as c on  b.spras = c.spras
                                           and c.sprsl = $session.system_language
{
      @UI.hidden: true
  key a.spras as LanguageKey, -- '3', 'E'

      @Search.defaultSearchElement: true
      @UI.textArrangement: #TEXT_LAST
      @ObjectModel.text.element: ['LanguageName']
      b.laiso as Language, -- 'KO', 'EN'

      @Semantics.text: true
      @Search.defaultSearchElement: true
      c.sptxt as LanguageName -- 'Korean', 'English'
}
```

#### CDS View 네이밍 체계 재확인
| 접두어 | 종류 | 역할 |
| --- | --- | --- |
| `ZR_B##_XXX` | Root BO View | RAP BO의 Root Entity. DB 테이블 직접 Select 또는 Interface View 이용, BO 핵심 구조(Key/Composition/Association) 정의 |
| `ZI_B##_XXX` | Interface View | 타 BO나 외부 시스템과의 인터페이스용 View, 타 BO에서 Association으로 참조 |

#### Root BO View ([`ZR_B07_SKA1`](../../reference/02_fi-account.md) · [코드 보기](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/02_fi-account/cds/ZR_B07_SKA1.ddls.asddls))

```
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: 'FI 계정 Root Entity'
@Metadata.ignorePropagatedAnnotations: true
define root view entity ZR_B07_SKA1 as select from ztb07ska1
composition[0..*] of ZI_B07_SKA1TEXT as _Ska1Text

association[0..1] to I_GLAccountTypeText as _TypeText
  on $projection.Glact = _TypeText.GLAccountType
  and _TypeText.Language = $session.system_language
{
    key sak_uuid as SakUuid,
    saknr as Saknr,
    glact as Glact,
    _TypeText.GLAccountTypeName as GlactText,
    bukrs as Bukrs,
    waers as Waers,
    mitkz as Mitkz,
    xloev as Xloev,
    @Semantics.user.createdBy: true
    created_by     as CreatedBy,
    @Semantics.systemDateTime.createdAt: true
    creation_at    as CreationAt,
    @Semantics.user.lastChangedBy: true
    changed_by     as ChangedBy,
    @Semantics.systemDateTime.lastChangedAt: true
    changed_at     as ChangedAt,
    @Semantics.systemDateTime.localInstanceLastChangedAt: true
    loc_changed_at as LocChangedAt,
    _Ska1Text // Make association public
}
```
