### 공급업체 마스터 테이블 ([`ZTB07LFA1`](../../reference/03_vendor.md) · [코드 보기](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/03_vendor/tables/ZTB07LFA1.tabl.asddls))
제시된 필드 구성에서 구매그룹/구매조직/거래 상태(trade_status) 추가

```
@EndUserText.label : '공급업체 마스터'
@AbapCatalog.enhancement.category : #NOT_EXTENSIBLE
@AbapCatalog.tableCategory : #TRANSPARENT
@AbapCatalog.deliveryClass : #A
@AbapCatalog.dataMaintenance : #ALLOWED
define table ztb07lfa1 {

  key client   : abap.clnt not null;
  key lif_uuid : abap.raw(16) not null;
  lifnr        : zeb07lifnr not null;
  name1        : name1;
  ekorg        : ekorg;
  ekgrp        : ekgrp;
  waers        : bstwa;
  @Semantics.amount.currencyCode : 'ztb07lfa1.waers'
  minbw        : minbw;
  fdgrv        : zeb07fdgrv;
  akont        : akont;
  loevm        : loevm_x;
  include zsb07timestamp;

}
```

**추가 필드 배경**
- `fdgrv`(공급업체분류): 자금계획 및 현금흐름 관리를 위해 공급업체를 구분하는 그룹(Planning Group)
- `akont`(조정계정): 매출채권·매입채무 등 보조원장을 총계정원장(G/L)과 자동으로 연계하는 계정 — SKA1의 계정 정보 중 매입채무 관련 계정 선택 (예: 21100000)

**공급업체 분류 (ZDB07FDGRV)**: A1 국내지급 / A2 해외지급 / A3 구매처 관계회사 / A4 주요 공급업체 / A5 인건비 / A6 세금

### Root BO View ([`ZR_B07_LFA1`](../../reference/03_vendor.md) · [코드 보기](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/03_vendor/cds/ZR_B07_LFA1.ddls.asddls))
Text Table은 없는 구조라 테이블 하나로만 구성. 처음엔 단순 Select만 했다가, 텍스트가 필요해서 다시 수정함 → 공급업체분류 텍스트(`_FdgrvText`), 조정계정(SKA1) 연결(`_Account`) association 추가.

```
association[0..*] to I_DomainFixedValueText as _FdgrvText
    on _FdgrvText.SAPDataDictionaryDomain = 'ZDB07FDGRV'
    and $projection.Fdgrv = _FdgrvText.DomainValue

// ...
fdgrv          as Fdgrv,
_FdgrvText[1: Language = $session.system_language ].DomainText as Fdgxt,
```
```
association[0..1] to ZR_B07_SKA1 as _Account
    on $projection.Akont = _Account.Saknr
// ...
akont          as Akont,
_Account._Ska1Text[1: Spras = $session.system_language ].Saktx as Akontxt,
```

SKA1 연결을 다시 수정하면서, 계정 타입 및 텍스트도 함께 끌어옴:
```

_Account.Glact as Glact,
_Account.GlactText as Glactxt,

### UI 구성 — Metadata Extension ([`ZC_B07_LFA1`](../../reference/03_vendor.md) · [코드 보기](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/03_vendor/cds/ZC_B07_LFA1.ddlx.asddlx))
facet 4개(공급업체/계정/구매/기타 정보)로 구성. 보고서 UI 예시 사진과 비교하며 정리하다 보니 알게 된 것들:

1. Behavior까지 생성해서 Create/Edit이 실제로 되는지 테스트해봐야 함
2. 계정 정보에서 해당 조정계정에 대한 정보를 SKA1에서 긁어와야 함
3. 거래 종료(`Loevm`)는 체크박스로 보여야 함
4. 공급업체 분류는 Create 시 필수값 지정 + F4 Help 연결이 필요함
5. 통화(KRW)는 비활성화 + 기본값 할당 등 기본 구성이 필요함

### [4.1~4.2] CRUD 기능 + Draft

| 기능 | 구현 방식 | 상세 설명 |
| --- | --- | --- |
| Create | Managed | 생성시 필수값: 공급업체 분류. 주문 통화는 KRW로 설정(Read Only). 저장시 필수값 체크(분류, 공급업체명). 공급업체번호는 자동 채번(Number Range) |
| Update | Managed | etag 기반 낙관적 락. 공급업체번호/주문통화는 수정불가 |
| Delete | Managed | - |

Draft Action: Edit(편집 전환) / Activate(검증 후 활성화) / Discard(취소) / Resume(재개) / Prepare(활성화 전 사전 검증)

**보고서 요구사항 반영**
1. 생성 시 공급업체 분류 필수 → `field ( mandatory : create ) Fdgrv;`
2. 공급업체번호는 자동채번이라 통화와 함께 read only → `field ( readonly ) Lifnr, Waers;`
3. 주문 통화는 KRW로 초기값 세팅 → Determination
4. 저장 시 공급업체 분류/공급업체명 필수값 체크 → Validation
5. 공급업체 번호 자동 채번 → 분류 코드별로 Number Range 앞자리를 다르게 설정(A1→01 ... A6→06)

determination SetInitialDefault on modify { create; }
// 로컬 클래스
METHOD SetInitialDefault.
    MODIFY ENTITIES OF zr_b07_lfa1 IN LOCAL MODE
    ENTITY zr_b07_lfa1
    UPDATE FIELDS ( Waers )
    WITH VALUE #( FOR key IN keys
                    ( %tky = key-%tky
                      Waers = 'KRW' )
                ).
ENDMETHOD.
```

validation CheckInit on save {  create; update; }

```

// 공급업체 번호 자동 채번 (분류 코드에 따라 Number Range 앞자리 다르게)
METHOD SetVendorNumber.
  " CASE ls_vendor-Fdgrv. WHEN 'A1'. lv_nr_range = '01'. ... WHEN 'A6'. lv_nr_range = '06'.
  " CALL FUNCTION 'NUMBER_GET_NEXT' EXPORTING nr_range_nr = lv_nr_range object = 'ZNR_B07LIFNR'
  " (전체 코드는 위 링크 참고)
ENDMETHOD.
```
