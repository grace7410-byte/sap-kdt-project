#### [4.1] CRUD 기능 — BDEF
초기엔 create/update/delete만 있는 스켈레톤으로 Active부터 확인:
```
managed implementation in class zbp_r_b07_t030 unique;
strict ( 2 );

define behavior for ZR_B07_T030
persistent table ZTB07T030
lock master
authorization master ( instance )
//etag master <field_name>
{
  create;
  update;
  delete;
}
```

**요구사항 기준 정리**
1. UUID 자동채번: `field ( numbering : managed, readonly ) MapUuid;`
2. 생성 시 필수값: `field ( mandatory : create ) Bwart, Ktosl, Saknr;`
3. 변경 시 수정 불가(이동유형/회계결정코드/계정타입): `field ( readonly : update ) Bwart, Ktosl, Glact;`
4. 이동유형에 따른 순번은 같은 이동유형 내 최대값+1로 자동 저장 → Determination을 말하지만 일단 Seqnr도 readonly 처리
5. 타임스탬프 등 관리 필드 readonly 추가
6. 존재하는 계정번호 확인 → Validation

**Determination/Validation 전 기본 설정**: `etag master <field_name>` 주석 풀고 `ChangedAt` 추가, mapping 완료, 클래스 생성 → Active

**본격 Determination/Validation**: `SetSequenceNumber`(최대 순번+1 자동채번), `CheckAccountExist`(SKA1 존재 여부 검증) — 2개를 한 번에 생성. 코드는 [`ZR_B07_T030`](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/04_account-determination/bdef/ZR_B07_T030.bdef.asbdef) / [구현 클래스](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/04_account-determination/bimp/zbp_r_b07_t030.clas.abap) 참고 (기존에 이미 반영돼 있던 코드와 일치함을 재확인)

cf. Validation 네이밍 룰 추천받기
```
CheckExist / CheckRequired / CheckEmpty / CheckDuplicate / CheckUnique / CheckValid(유효한지) / CheckAmountPositive(금액이 양수인지)
```

### 오류 해결하기

#### ⭐ [01] 자재 — WAERS Control

**에러 메시지**: `A static read-only field 'WAERS' is not allowed for an editable amount field`

**원인**: `field ( readonly ) Waers;`로 정적 readonly를 걸었는데, `Stprs`(표준가격)에 `@Semantics.amount.currencyCode: 'Waers'` 어노테이션이 붙어 있어서 `Stprs`는 편집 가능한 필드로 취급됨 → 컴파일 타임 고정 readonly와 모순 발생

**해결**: `field(readonly)` 대신 `field(features:instance)`로 동적 제어 전환
```
field ( features : instance ) Waers;
//  field ( readonly ) Waers; // 이건 에러남 (정적 제어)
```
```
METHOD get_instance_features.
  result = VALUE #( FOR key IN keys
                       ( %tky          = key-%tky
                         %field-Waers  = if_abap_behv=>fc-f-read_only ) ).
ENDMETHOD.
```
