### ⭐ [01] 자재 — WAERS Control → 해결 완료
어제 도입한 동적 제어(`features:instance`)를 개선. **"신규 생성 중"이면 편집 가능**하고 **"기존 데이터 수정 중"이면 read-only**가 되도록 조건부로 처리(UUID로 DB 조회해서 존재 여부로 판단).

```
METHOD get_instance_features.
  " Uuid를 조회한 뒤, DB(ZTB07MARA)에 데이터가 있는지로 신규/수정 판단
  " 조회 성공 = 수정 중 = read only, 조회 실패 = 신규 생성 중 = 편집 가능
  " (6개 필드: Werks/Lgort/Mtart/Bklas/Matnr/Ersda가 이 조건부 제어 대상, Waers는 항상 read-only)
ENDMETHOD.
```
(전체 코드는 [`구현 클래스`](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/01_material-mgmt/bimp/zbp_r_b07_mara.clas.abap) 참고)

**[01] 자재 ++) → 해결 완료** — Waers로 알아낸 동적 제어를 다른 필드들에도 확장 적용. 보고서의 Create/Edit 예시와 비교했을 때: Create → 팝업 → 화면 진입 시엔 수정 가능하고, (이미 있는 데이터) Edit일 때만 수정이 막히도록 구성됨. Output Only(정적 readonly)와 Input만 막힌 상태는 화면 상에서 비주얼이 다르다는 점도 확인.

### [01] 자재 — 무한루프 오류 → 해결 완료

🐛 (1) SetReadOnly
이미 Matfi='X' 플래그가 설정된 레코드에도 계속 MODIFY를 실행 → MODIFY 실행 시 데이터가 변경된 것으로 인식되어 on-save determination이 다시 트리거됨 → 다시 X를 MODIFY함 → 무한 반복(ENDLESS_ON_SAVE_DUMP).

✅ 해결: 이미 'X'인 레코드는 업데이트 대상에서 제외하고, 실제로 값이 바뀌어야 하는 경우에만 MODIFY 실행

🐛 (2) SetLanguageDefault
MaraText 생성 시에도 Spras가 이미 채워져 있는 경우 계속 MODIFY됨 → 마찬가지로 무한루프(또는 EMPTY_UPDATE 계약위반) 가능성.

✅ 해결: Spras가 비어있는 경우에만 MODIFY하도록 필터링

두 메서드 다 [`ZR_B07_MARA`](../../reference/01_material-mgmt.md) 구현 클래스에 반영 — [코드 보기](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/01_material-mgmt/bimp/zbp_r_b07_mara.clas.abap)

> `SetLanguageDefault`는 자재명(Child, alias `MaraText`) 쪽 Determination이라, 이번에 처음으로 `ZI_B07_MARATEXT`(alias `MaraText`)의 Behavior Definition도 [`ZR_B07_MARA.bdef.asbdef`](https://github.com/grace7410-byte/sap-kdt-project/blob/main/src/01_material-mgmt/bdef/ZR_B07_MARA.bdef.asbdef)에 함께 정리했다.

### [03] 공급업체 — Lifnr 채번 오류 → 해결 완료
Prefix('V')를 하고 싶었는데 그냥 숫자로만 채번되어버림. NR 생성 자체에서 Prefix 하려면 Sub type 지정이 필요하고, 그러려면 연결 가능한 도메인/데이터 엘리먼트를 새로 만들어야 해서 그렇게는 안 하고, **숫자는 6자리만 채번(어차피 0000 붙어서 최종 10자리)한 뒤 로직에서 앞에 'V'를 붙이는 방식**으로 우회.

```
IF sy-subrc = 0. " prefix 하려면 뒤에서 6자리 끌어와서 앞에 V 붙여주기
  DATA(lv_seq) = substring( val = lv_number off = strlen( lv_number ) - 6 ).
  DATA(lv_lifnr) = |V{ lv_seq }|.
  APPEND VALUE #( %tky = ls_vendor-%tky Lifnr = lv_lifnr ) TO lt_update.
```
Number Range 오브젝트명도 `ZNR_B07LIFNR` → `ZNRB07_LIF`로 변경. A2일 때도 테스트해서 정상 채번 확인함.
